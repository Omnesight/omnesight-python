# Security Policy

## Supported Versions

Only the latest active minor release of the Omnesight Python SDK receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

Omnesight takes the security of our infrastructure and users seriously.

If you believe you have found a security vulnerability in the Omnesight Python SDK:

1. **Do not disclose the issue publicly.** Do not open a public GitHub issue.
2. Send an email to **security@omnesight.com** or **solutions@omnesight.com** with:
   - A clear description of the vulnerability.
   - Proof of Concept (PoC) or minimal reproduction steps.
   - Affected versions and environments.
   - Potential impact.
3. Our security team will acknowledge receipt within 24–48 hours and coordinate remediation.
